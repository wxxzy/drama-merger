# 06 · 字幕时间轴重映射

> 对应源码：`drama_merger/subtitles.py`
> 学习目标：理解「为什么分集字幕合并后会错位」以及如何自动修正。

## 一个隐蔽的陷阱

短剧字幕有个坑：**每一集的字幕都从 `00:00:00` 开始计时**。

假设三集各 6 秒，直接把三个 SRT 拼起来会得到：

```
第1集.srt:  00:00:00 --> 00:00:06   （正确）
第2集.srt:  00:00:00 --> 00:00:06   ✗ 应该是 00:00:06 --> 00:00:12
第3集.srt:  00:00:00 --> 00:00:06   ✗ 应该是 00:00:12 --> 00:00:18
```

结果：第 2 集的对白会跑到第 1 集的时间段里播放，全片字幕错位。

**解决办法**：按每集在成片中的起始位置，整体平移该集字幕的时间轴。

## Cue —— 一条字幕

```python
# subtitles.py:21
@dataclass
class Cue:
    start: float
    end: float
    text: str

    def shifted(self, offset: float) -> "Cue":
        """把这条字幕整体后移 offset 秒。"""
        return Cue(self.start + offset, self.end + offset, self.text)
```

## 支持三种格式

`subtitles.py` 提供完整的解析/序列化：

| 格式 | 解析 | 输出 |
|---|---|---|
| SRT | `parse_srt()` | `to_srt()` |
| VTT | `parse_srt()`（语法兼容） | `to_vtt()` |
| ASS | `parse_ass()` | `to_ass()` |

时间格式转换函数一应俱全：`parse_srt_time`/`format_srt_time`、
`format_vtt_time`、`parse_ass_time`/`format_ass_time`。输出沿用原格式。

## 找配套字幕

`find_subtitles_for(video)` 按三级策略找字幕：

1. 同目录**同名**（`第1集.mp4` → `第1集.srt`）
2. 同名字**前缀**
3. 目录内**唯一**字幕文件

容错做得比较宽松，适配常见的素材组织方式。

## merge_subtitles()：核心

```python
# subtitles.py:253（概念示意）
def merge_subtitles(episodes: list[EpisodeSubtitle], out_path):
    offset = 0.0
    all_cues = []
    for ep in episodes:
        for cue in ep.cues:
            all_cues.append(cue.shifted(ep.offset))   # 关键：逐集平移
        offset += ep.duration
    # 按目标格式序列化输出
    ...
```

`EpisodeSubtitle` 携带该集的 `offset`（起始位置）。调用方（cli/gui）在收集字幕时
逐集累加时长算出 offset：

```python
# cli.py:357
offset = 0.0
for info in items:
    subs = find_subtitles_for(info.path)
    if subs:
        episodes.append(EpisodeSubtitle(info.path, subs, offset=offset))
    offset += info.duration     # 下一集的起点 = 本集结束
```

**实测效果**（3 集 × 6 秒）：

```
第1集.srt (+0.00s,  3条)
第2集.srt (+6.00s,  3条)
第3集.srt (+12.00s, 3条)
```

## 外挂字幕 vs 硬字幕

工具提供两种处理方式：

- **外挂字幕**（`--subtitles`）：生成合并后的 `.srt/.vtt/.ass`，播放时可选，不改动画面；
- **硬字幕**（`--burn-subtitles`）：用 `burn_subtitles()` 把字幕烧进画面，任何播放器都能看到，
  但耗时较长（要重编码整片）。

GUI 里的「烧入字幕（若存在）」勾选项走的是硬字幕路径。

## 小结

- 分集字幕各自从 0 计时 → 直接拼接必然错位；
- `Cue.shifted(offset)` 逐集平移，`offset` 由累计时长算出；
- 三种格式通吃，外挂/硬字幕两种输出。
