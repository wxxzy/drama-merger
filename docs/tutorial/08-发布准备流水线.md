# 08 · 发布准备流水线

> 对应源码：`drama_merger/publish.py`
> 学习目标：理解如何从成片一键生成 YouTube 发布所需的三样东西。

## 三样产物

合并完成后，发布到 YouTube 还要准备：

| 产物 | 说明 |
|---|---|
| **章节时间轴** | 按各集真实时长累加，粘进简介后观众可直接跳集 |
| **发布文案** | 标题 / 简介（含章节）/ 中英标签，逐块可复制 |
| **缩略图** | 竖屏封面转 1280×720 横屏，自动去掉封面自带文字与水印 |

`publish.py` 把整条链路收进库内，供 GUI 与 CLI 共用。

## 数据中心：DramaMeta

数据与逻辑分离——每部剧的元信息用一个 dataclass 描述：

```python
# publish.py:26
@dataclass
class DramaMeta:
    title: str          # 剧名
    genre: str          # 题材
    yt_title: str       # YouTube 中文标题（钩子前置）
    yt_title_en: str    # 英文备选标题
    desc_cn: str        # 中文简介
    desc_en: str        # 英文简介
    tags: list[str]     # 中文标签
    tags_en: list[str]  # 英文标签
    alt_titles: list[str]  # 备用标题（A/B 测试文案）
    cover: str          # 封面文件名
    top_cut/bottom_cut  # 缩略图裁剪比例
    thumb_title/thumb_sub  # 缩略图上的文字
```

## 模板系统

`DRAMA_TEMPLATES` 是「剧名 → DramaMeta」的注册表：

```python
DRAMA_TEMPLATES = {
    "回乡建房报旧仇": DramaMeta(
        yt_title="回乡建房报旧仇｜被村霸欺压三十年，我盖楼让他破产疯癫 #短剧",
        ...
        cover="3：4.png", bottom_cut=0.235,
        thumb_title="回乡建房报旧仇",
    ),
}
```

- `match_template(title)`：宽松匹配（容忍「（36集）」等后缀），命中就用现成文案；
- `generic_meta(title)`：匹配不到时生成通用文案，保证流程永远可用。

**设计要点**：模板放在库模块 `publish.py`，而不是 `gui.py`。
否则命令行版会被迫依赖 tkinter（真实踩过的坑，见 [11](./11-踩坑集锦.md)）。

新增剧目文案：往 `DRAMA_TEMPLATES` 加一条即可（详见 [12](./12-测试与扩展指南.md)）。

## 章节时间轴

```python
def build_chapters(video_files):
    """入参 (集号, 时长) 按集号排序，返回 [(起始秒, 集号)]。"""
    t = 0.0
    for ep, dur in video_files:
        chapters.append((t, ep))
        t += dur
```

`fmt_ts()` 把秒数转成 YouTube 格式：不足 1 小时用 `M:SS`，超过用 `H:MM:SS`。
`ep_num()` 从文件名提取集号，支持多种命名（「第10集」「(12)」「-3」）。

## 发布文案

`build_description()` 生成整段简介（中文简介 + 剧集信息 + 章节 + 英文 Synopsis + hashtags）。
`build_publish_txt()` 把标题、简介、标签、备用标题、缩略图说明、发布建议拼成一个「逐块可复制」的文本文件。

有个实用细节：`tags_length_warning()` 检查中英标签合计是否超过 YouTube 的 500 字符上限，
超限会给出提醒。

## 缩略图生成

`make_thumbnail()` 用 Pillow 把竖屏封面转成 1280×720 横屏，构图是：

```
原图放大模糊铺底 + 压暗
        +
封面贴右侧
        +
左侧暗渐变压字（品牌角标 + 主标题 + 副标题 + 底部信息条）
```

几个精心处理：

- `_trim_border()` 裁掉封面自带的细边框；
- `_crop_by_ratio(top_cut, bottom_cut)` 裁掉封面自带的剧名与生成水印
  （模板里 `bottom_cut=0.235` 就是为去掉底部红字调出来的，见 [11](./11-踩坑集锦.md)）；
- `_fit_text()` 自动缩字号，保证标题不超出宽度；
- 副标题用实色绘制——描边会与主标题描边叠加出重影。

**容错**：没装 Pillow 时只跳过缩略图、其余产物照常生成（GUI 版打包装了 Pillow，CLI 版可选）。

## 编排入口：generate_all()

```python
def generate_all(meta, episodes, out_dir, cover_dir=None, ...):
    # 1. 章节时间轴 -> 章节时间轴.txt
    # 2. 发布文案   -> 各剧/<剧名>.txt
    # 3. 缩略图     -> 缩略图/01_<剧名>.jpg
    return PublishOutput(...)
```

`episodes` 是 `[(集号, 时长)]`，需要按集号排序。调用方负责收集：

- CLI `cmd_publish()`：从 `--source` 目录探测每集时长；
- GUI `_pub_collect_episodes()`：优先用素材目录的分集文件（最准），找不到才放弃。

## 小结

- `DramaMeta` 数据 + `generate_all` 逻辑，数据与生成分离；
- 模板系统：命中用现成文案，未命中生成通用文案；
- 章节严格按各集真实时长累加，与成片对齐；
- 缩略图构图 + 裁剪/水印处理，容错到「没 Pillow 也能出其他产物」。
