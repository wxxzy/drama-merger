- **只想用**：读 [01](./01-快速上手.md)。
- **想理解设计**：读 [00](./00-学习路线.md) → [02](./02-整体架构.md)，再挑感兴趣的模块。
- **要二次开发 / 排错**：通读全部，重点看 [05 策略引擎](./05-合并策略引擎.md)、
  [11 踩坑集锦](./11-踩坑集锦.md)、[12 测试与扩展](./12-测试与扩展指南.md)。
