# 12 · 测试与扩展指南

> 对应源码：`tests/`、`tools/`、`publish.py`、`compress.py`
> 学习目标：学会跑测试，并知道如何安全地扩展功能。

## 测试体系

```bash
# 1. 生成测试素材（4 类场景）
python tests/make_fixtures.py

# 2. 跑完整回归测试
python tests/run_tests.py
```

`tests/` 下按场景组织素材：

| 场景目录 | 覆盖内容 |
|---|---|
| `scene1_uniform` | 参数完全一致 → 策略 A |
| `scene2_mixed` | 参数混杂 → 归一化/无损判定 |
| `scene3_cn_names` | 中文文件名、自然排序 |
| `scene4_edge` | 边界：无音轨、损坏文件等 |
| `scene5_minimal` | 少数偏离 → 策略 D |

回归测试覆盖约 38~49 项检查：环境探测、自然排序（ep2 < ep10）、一致性分析、
各策略、字幕时间轴重映射、裁剪淡变、损坏文件容错等。

## 扩展指南

### 如何新增一部剧的发布文案

在 `publish.py` 的 `DRAMA_TEMPLATES` 加一条：

```python
DRAMA_TEMPLATES["新剧名"] = DramaMeta(
    title="完整剧名",
    genre="题材 · 标签",
    yt_title="带钩子的中文标题 #短剧",
    yt_title_en="English title #Shorts",
    desc_cn="中文简介...",
    desc_en="English synopsis...",
    tags=["标签1", "标签2", ...],
    tags_en=["tag1", "tag2", ...],
    cover="封面文件名.png",
    bottom_cut=0.0,        # 按封面实际情况调
    thumb_title="缩略图短标题",
    thumb_sub="副标题",
)
```

`match_template()` 会自动匹配（宽松匹配剧名）。缩略图 `bottom_cut` 可用红色像素扫描
定位封面自带文字的起始位置来调（见 [11](./11-踩坑集锦.md) 坑 12）。

### 如何新增一个压缩档位

在 `compress.py` 的 `PRESETS` 加一条 `CompressPreset`：

```python
PRESETS["my-preset"] = CompressPreset(
    name="my-preset", label="我的档位", codec="x264",
    crf=27, audio_kbps=96, max_height=1280, fps_cap=30,
    speed="fast", desc="自定义说明",
)
```

CLI 的 `--compress` 和 GUI 的下拉框都会自动出现新档位（都从 `PRESETS` 动态读取）。

> 若同时在 `tools/compress_videos.py` 里维护了同名档位，记得两处保持一致。

### 如何新增一个合并策略

1. 在 `merger.py` 的 `Strategy` 枚举加值，并补 `label`；
2. 写 `build_xxx_cmd()` 构建 ffmpeg 命令；
3. 在 `choose_strategy()` 加决策分支；
4. 在 `plan_merge()` 加对应处理分支；
5. 在 `execute_merge()` 的降级链里决定是否纳入；
6. 补测试。

策略的实现范式是「命令构建函数 + 决策分支 + 规划分支」三件套。

## 源码阅读顺序建议

```
ffmpeg_env.py  →  probe.py  →  compress.py / subtitles.py
       ↓
merger.py（核心，多读几遍）
       ↓
publish.py  →  cli.py / gui.py  →  build.spec
```

## 小结

- `make_fixtures.py` 生成素材，`run_tests.py` 跑回归；
- 新增剧目改 `publish.py` 模板，新增压缩档位改 `compress.py` 的 PRESETS；
- 新增策略要动 `merger.py` 四处（枚举/命令/决策/规划）。

## 结语

这套工具的核心不是「会调 ffmpeg」，而是**知道什么时候不该重编码**、以及
**把每个坑都变成代码里的防御**。希望这份教程能帮你读懂它、改进它。

Happy merging!
