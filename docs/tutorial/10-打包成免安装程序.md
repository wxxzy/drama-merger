# 10 · 打包成免安装程序

> 对应源码：`build.spec`、`cli_entry.py`、`gui_entry.py`、`打包.bat`
> 学习目标：理解如何产出一个「拷到任何 Windows 电脑都能用」的自包含文件夹。

## 目标产物

双击 `打包.bat`（内部调用 PyInstaller），生成：

```
dist/短剧合并工具/
    短剧合并工具.exe            ← 图形界面（无黑框）
    短剧合并工具-命令行.exe      ← 命令行（保留控制台）
    _internal/                  ← 运行时 + ffmpeg（两个 exe 共享）
```

整个文件夹可直接拷到其他电脑（哪怕没装 Python、没装 ffmpeg）。

## build.spec 的设计要点

`build.spec` 用 PyInstaller 的 onedir 模式，一次构建两个 EXE。三个关键设计：

### 1. 两个 exe 共享一个 `_internal`

GUI 与 CLI 用同一个 `COLLECT` 收集，共享运行时目录。ffmpeg 只存一份（约 83MB），不翻倍。

### 2. 手动捆绑 ffmpeg，排除 imageio_ffmpeg 包

```python
# build.spec:25
def _find_ffmpeg():
    import imageio_ffmpeg
    return imageio_ffmpeg.get_ffmpeg_exe()

_FFMPEG = _find_ffmpeg()
_datas = [(_FFMPEG, "ffmpeg")]   # -> _internal/ffmpeg/ffmpeg.exe
```

同时在 `excludes` 里排除 `imageio_ffmpeg`——否则 PyInstaller 会把它那 83MB 二进制
再打一份。改为手动放入 ffmpeg，由 entry 脚本注入环境变量定位。

### 3. GUI 无控制台，CLI 保留控制台

```python
# GUI
console=False     # 不弹黑框
# CLI
console=True      # 必须保留——否则子进程管道拿不到句柄，ffmpeg 进度回调失效
```

这是个容易踩的坑：如果 CLI 也用 windowed，subprocess 的 stdout/stderr 管道会异常，
进度解析就废了。

### 4. hiddenimports 与 excludes

- `hiddenimports` 显式列出所有 `drama_merger.*` 模块 + tkinter 子组件 + PIL 需求；
- **不能排除 PIL**（publish 生成缩略图需要）——历史版本中误排除了 PIL，导致打包版缩略图失败；
- CLI 版可以排除 tkinter（它不启动界面）。

## 两个 entry 的打包适配

见 [09](./09-命令行与图形界面.md)：`_bootstrap_ffmpeg()` 注入 ffmpeg 路径、
`_NullWriter` 兜底 stdout、不 chdir。这些「看似多余」的代码，全是为打包环境准备的。

## 打包流程

```bash
# 1. 双击 打包.bat（或手动）
pyinstaller --clean build.spec

# 2. 产物在 dist/短剧合并工具/
# 3. 验证：把整个文件夹拷到干净环境，双击 exe
```

`打包.bat` 会自动检测并安装 PyInstaller（走清华镜像）。

## Windows BAT 的两个硬性要求

`.bat` 文件必须满足，否则会报 `'xx' 不是内部或外部命令`：

1. **换行符必须是 CRLF**（`0d 0a`）。Git/Linux 工具生成时容易变成纯 LF，
   CMD 会把两行拼成一条命令执行，出现乱码报错。
2. **编码用 GBK（ANSI 936）**，与中文 Windows 控制台原生一致，无需切代码页。

仓库内的 `.bat` 均已按此处理。如需改动，用 Python 写字节而非文本编辑器保存：

```python
from pathlib import Path
text = "...".replace("\n", "\r\n")
Path("xxx.bat").write_bytes(text.encode("gbk"))
```

## 常见打包问题

| 现象 | 原因 | 解法 |
|---|---|---|
| exe 双击闪退 | windowed 下 print/stdout 崩溃 | `_NullWriter` 兜底 |
| 缩略图生成失败 | excludes 排除了 PIL | 从 excludes 移除 PIL |
| 找不到 ffmpeg | 捆绑文件名带版本号 | `_bootstrap_ffmpeg` 按模式匹配 |
| 输出文件「消失」 | entry 里 chdir 了 | 移除 chdir |
| dist 目录被锁 | 残留进程占用 | 关掉 GUI/ffmpeg 进程，或换 `--distpath` |
| BAT 报「不是内部命令」 | LF 换行 | 转 CRLF + GBK |

## 小结

- onedir 模式，两个 exe 共享 `_internal`，ffmpeg 只一份；
- 手动捆绑 ffmpeg + 排除 imageio_ffmpeg 包 + 注入环境变量；
- GUI 无控制台、CLI 保留控制台；PIL 不能排除；
- BAT 必须 CRLF + GBK。
