# 01 · 快速上手：5 分钟跑通

> 学习目标：不改任何代码，用三种方式各跑一次，理解「输入是什么、输出是什么」。

## 准备一个测试目录

把若干集短剧放进一个目录，例如：

```
D:/短剧/某剧/
    第1集.mp4
    第2集.mp4
    第3集.mp4
    ...
```

文件名带数字即可，工具会**自然排序**（第2集排在第10集前面，不会出现 1、10、2 的乱序）。

## 方式一：免安装版（推荐给非开发者）

项目根目录下双击 `打包.bat`，等约 1 分钟生成：

```
dist/短剧合并工具/
    短剧合并工具.exe            ← 图形界面
    短剧合并工具-命令行.exe      ← 命令行
    _internal/                  ← 运行时 + ffmpeg（自包含）
```

这个文件夹拷到任何一台 Windows 电脑（哪怕没装 Python、没装 ffmpeg）都能直接用。

- 双击 `短剧合并工具.exe` → 弹出图形界面（见方式二）
- 把短剧目录**拖到** `合并.bat` 上 → 一步完成探测+合并+字幕

## 方式二：图形界面

双击 `启动界面.bat`（会优先用打包版，否则回退到系统 Python）。

界面是两个标签页，对应前后相继的两条流水线：

```
① 合并视频     选目录 → 扫描并分析 → 设选项 → 点「▶ 开始合并」
② 发布准备     选成片 → 填剧名/封面 → 点「▶ 生成发布素材」
```

**合并页操作顺序**：

1. 「浏览...」选短剧目录；
2. 点「扫描并分析」→ 下方列出每集参数，并给出「将采用什么策略」的结论；
3. 在「4. 输出选项」里设输出路径、编码器、画质；
   - 想边合并边瘦身：勾「合并时直接压缩」，选档位（默认 `upload`）；
4. 点右下角「▶ 开始合并」，看进度条与日志。

合并完切到「② 发布准备」，点「用刚合并的成片」可自动带入剧名与封面，
再点「▶ 生成发布素材」即可产出章节、文案、缩略图。

> 关于「按钮在哪」：主操作按钮固定在每个标签页内容区的最下方 —— 合并页是
> 「▶ 开始合并」，发布页是「▶ 生成发布素材」。界面曾被挤到看不见按钮，
> 现在改用标签页 + 固定底部按钮区解决（详见 [11-踩坑集锦](./11-踩坑集锦.md)）。

## 方式三：命令行

源码运行（需 Python 3.11）：

```bash
# 1. 先看目录里有什么、能不能无损拼接（不改动任何文件）
python cli.py probe "D:/短剧/某剧"

# 2. 合并（自动选最优策略）
python cli.py merge "D:/短剧/某剧" -o "D:/输出/某剧全集.mp4"

# 3. 合并即压缩（一次成型，不产生中间大文件）
python cli.py merge "D:/短剧/某剧" --compress hevc

# 4. 由成片生成发布素材
python cli.py publish --source "D:/短剧/某剧" -o "D:/输出/youtube"

# 5. 查看所有压缩档位
python cli.py presets
```

`probe` 是最安全的第一步——它只读不写，会告诉你：

- 发现多少集、每集分辨率/帧率/音轨；
- 参数是否完全一致（一致就能秒级无损拼接）；
- 若不一致，差异在哪、建议走哪档策略；
- 有没有配套字幕。

## 一个典型输出

```
发现 3 个视频文件，开始探测...
  [1/3] 第1集.mp4  768x1344 24fps 18.0s ...
  ...
一致性分析
片段参数完全一致 -> 可走【策略A 无损拼接】（秒级完成，画质零损失）
目标输出参数：768x1344 @ 24fps，音频 44100Hz 2ch
```
```
采用策略：策略A · 无损拼接（不重编码，秒级完成，画质零损失）
执行步骤：
  - 无损拼接 3 个片段（不重编码）
合并完成！ 大小 21.4 MB，耗时 0.3 秒（60x 实时速度）
```

注意「编码器：无（直接复制原始码流，未重新编码）」——这是本工具的核心价值：
**能通过 `-c copy` 解决的，绝不碰画质。**

## 小结

- 三种入口（打包版 / GUI / CLI）共享同一套核心库，功能一致；
- `probe` 是了解素材的入口，`merge` 是主功能，`publish` 是发布延伸；
- 图形界面把「合并」和「发布」拆成两个标签页，操作路径清晰。
